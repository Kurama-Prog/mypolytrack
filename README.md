# MyPolyTrack

A low-poly browser racing game inspired by [PolyTrack](https://www.kodub.com/apps/polytrack).
Three handcrafted circuits, ghost replays, local leaderboards and **live
acceleration / brake tuning**.

Built with Vite + TypeScript + Three.js. All geometry is generated procedurally,
so there are no model or texture downloads.

## Run

```bash
npm install
npm run dev
```

Then open the printed local URL (defaults to http://localhost:5173).

Production build:

```bash
npm run build
npm run preview
```

## Controls

| Action | Keys |
| --- | --- |
| Accelerate | `W` / `↑` |
| Brake / reverse | `S` / `↓` |
| Steer | `A` / `D` or `←` / `→` |
| Restart the run | `R` |
| Pause | `Esc` |
| Mute / unmute audio | `M` |
| Confirm / start | `Enter` |

## Tuning

The HUD keeps a **TUNING** panel in the top-right corner during a run:

- **Acceleration** (`0.5×`–`2.0×`) — engine force multiplier.
- **Brake** (`0.5×`–`2.0×`) — braking force multiplier.
- **Handling** — `GRIP` for stable, planted cornering; `DRIFT` for a loose rear
  end that keeps sliding and needs opposite lock.

Every change applies on the next physics step (120 Hz), and the values are saved
to `localStorage`. The same panel is available from the pause menu and the main
menu settings.

## Audio

All sound is synthesised at runtime with the Web Audio API — there are no audio
files to download.

- **Engine** — pitched by speed, timbre opens with throttle, idles during the
  countdown and revs on `GO`.
- **Brakes** — filtered noise plus a squeal layer that fades in under hard
  braking at speed.
- **Circuit music** — a per-circuit loop generated by a look-ahead sequencer:
  - SUNSET VALLEY — 104 BPM warm synth-pop in A major, plucked arps.
  - NEON CANYON — 126 BPM dark electro in F# minor, pulsing bass.
  - VERTEX LOOP — 138 BPM tech-trance in D minor, four-on-the-floor and risers.
- **Event SFX** — countdown, `GO`, checkpoint chime, boost whoosh, landing
  thump, respawn, finish fanfare and UI clicks.
- **Mixer** — independent MUSIC / SOUND FX sliders in the settings and pause
  panels, plus a speaker toggle in the HUD. Pressing `M` mutes everything. Music
  is ducked (never stopped) while paused; levels and mute are saved to
  `localStorage` under `mypolytrack.v1.audio`.

## Features

- Fixed 120 Hz physics with a custom arcade car model (ground-locked frame +
  ballistic airborne phase), so loops and banked corners work without a
  third-party physics engine.
- Checkpoints with split times, respawn to the last checkpoint, `R` to restart.
- Ghost replay: your best run is recorded at 30 Hz, packed as base64 float data
  and replayed as a translucent car.
- Local top-5 leaderboard per circuit with dates (`localStorage`).
- Procedural low-poly scenery (trees, rocks, ice shards, distant peaks) with
  seeded randomness and merged geometry for a low draw-call count.

## Project layout

src/
├── main.ts                 app entry
├── engine/                 renderer, fixed-step loop, input, chase camera
├── physics/                arcade car model + tuning store
